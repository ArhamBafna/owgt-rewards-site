### Name
Plan a Project Kickoff

### Description
A powerful prompt to plan a project kickoff.

### Prompt
```text
I'm kicking off [project] with [team]. Write a 30-minute agenda
covering: what and why, how decisions get made, and 30-day
success. Include the one question that surfaces hidden concerns.
```
