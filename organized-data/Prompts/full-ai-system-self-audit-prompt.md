### Name
Full AI System Self-Audit Prompt

### Description
A comprehensive self-audit prompt designed to evaluate your current AI stack, tool efficiency, prompt usage, and agent setup.

### Prompt
```text
Conduct a complete diagnostic audit of my current AI ecosystem, workflows, and tool stack. 
Evaluate:
1. Tool redundancy and missing CLI/API equivalents.
2. Skill efficiency and recurring task automation opportunities.
3. Model routing strategy based on task complexity vs cost.
4. Gaps in context management and persistent memory systems.
Provide an actionable 5-step optimization roadmap.
```
