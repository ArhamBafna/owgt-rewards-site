### Name
Build a SOP for a Repeatable Process

### Description
A powerful prompt to build a sop for a repeatable process.

### Prompt
```text
Here's a process we run repeatedly: [describe]. Write an SOP that
covers each step in order, names owners, and flags the most common
failure point with a recovery action.
```
