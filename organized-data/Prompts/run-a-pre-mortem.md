### Name
Run a Pre-Mortem

### Description
A strategic template to run a pre-mortem.

### Content
```
I am about to commit to [decision or project]. Imagine it is 12 months from now and this has failed badly. Working backwards, what are the three most likely reasons it failed? For each one, what should I put in place now to reduce the probability?
```
