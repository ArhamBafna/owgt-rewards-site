### Name
Apply First Principles Thinking

### Description
A strategic template to apply first principles thinking.

### Content
```
Everyone in [industry/domain] assumes that [describe a common assumption]. Apply first principles thinking: break this assumption down into its component parts and tell me which parts are actually constraints and which parts are just habits. What would you do differently if you were starting from scratch with no inherited assumptions?
```
