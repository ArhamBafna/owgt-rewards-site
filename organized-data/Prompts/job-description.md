### Name
Job Description

### Description
A ready-to-use prompt that instructs the AI to: Write a job description for a [role] at my business.

### Prompt
```text
Write a job description for a [role] at my business. Company: [describe]. Responsibilities: [list]. Requirements: [list]. Tone: engaging, honest. Under 300 words.
```
