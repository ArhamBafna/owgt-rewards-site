### Name
Prioritize Between Competing Initiatives

### Description
A strategic template to prioritize between competing initiatives.

### Content
```
Here are the strategic initiatives I'm choosing between: [list]. Prioritize them using these criteria: expected impact on revenue or competitive position, resource requirements, time to first results, and risk if we deprioritize. Give me a ranked order with the one condition that would cause you to reorder the top two." CATEGORY 2 When something isn't working and you need to identify what's actually wrong before deciding how to fix it.
```
