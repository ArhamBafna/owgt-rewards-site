### Name
Refine Your Value Proposition

### Description
A powerful prompt to refine your value proposition.

### Prompt
```text
My current value proposition is: [state it]. Test it against a
skeptical [target customer]. What is the first objection they
raise? Rewrite the value proposition to preempt that objection
before it gets asked.
```
