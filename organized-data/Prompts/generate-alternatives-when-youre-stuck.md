### Name
Generate Alternatives When You're Stuck

### Description
A strategic template to generate alternatives when you're stuck.

### Content
```
I've been trying to solve [problem] by [current approach] and it's not working. Generate five genuinely different alternative approaches, specifically ones that challenge the assumption that [state your core assumption]. For each one, tell me what it requires that we don't currently have.
```
